### What's new

- **Click to play.** Games and ROMs now start when you click them (or pick one with the arrow keys and press Return), so moving the pointer across the notch never starts one by accident. Prefer starting games by resting the pointer on them? Choose it in **Settings → Notch → Start a game**.
- **No stray clicks.** A click in the first moment after the notch opens is ignored, so a click meant for something under the notch doesn't start a game.

Everything from [0.2.0](https://github.com/jeothecreator/Notcher/releases/tag/v0.2.0) is here too: drag NES and Game Boy ROMs onto the notch to play them, the Library page, the demo games and the new built-in games.
